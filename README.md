# 📦 Free Install Microsoft Office

Данный репозиторий содержит актуальные инструкции по бесплатной установке и активации Microsoft Office (включая версию 2024 года). 

> ⚠️ **Внимание:** Инструкция предоставлена в ознакомительных целях. После ознакомления рекомендуется приобрести официальную лицензию.

---

## 🚀 Основной способ (Актуальный): Office Tool Plus + Ohook

Этот метод является наиболее надежным на текущий момент. Он позволяет скачать оригинальный дистрибутив Office напрямую с серверов Microsoft и активировать его с помощью скрипта Ohook.

### Шаг 1: Удаление неактивированного Microsoft Office

Если на компьютере остался неактивированный Microsoft Office или его компоненты, перед установкой новой версии его необходимо удалить.

#### Способ 1: Удаление через панель управления (рекомендуется)

Для большинства случаев установки Office достаточно стандартного удаления через панель управления Windows.

1. Нажмите клавишу **Windows**, введите `панель управления` и откройте её.
2. Перейдите в раздел **Программы** > **Программы и компоненты**.
3. Найдите в списке **Microsoft Office** или **Microsoft 365**, нажмите на него правой кнопкой мыши и выберите **Удалить**.
4. Следуйте инструкциям на экране для завершения удаления.

> **Примечание**: Если Office не отображается в панели управления, возможно, он установлен из Microsoft Store. В этом случае перейдите в **Параметры** > **Приложения** > **Установленные приложения**, найдите Office и выберите **Удалить**.

#### Способ 2: Использование средства Get Help (версия для командной строки)

Если стандартное удаление через панель управления не удалось, можно воспользоваться официальным сценарием удаления Office из состава приложения **Get Help** (в русской версии — «Получить помощь»). Компания Microsoft перенесла функцию очистки `SetupProd_OffScrub.exe` в это приложение, и теперь удаление выполняется через командную строку с использованием `GetHelpCmd.exe`.

**Порядок действий**:

1. Скачайте версию **Get Help для командной строки** с официальной страницы Microsoft по [ссылке](https://learn.microsoft.com/ru-ru/troubleshoot/microsoft-365/admin/miscellaneous/get-help-office-uninstall)
2. Распакуйте скачанный архив в любую удобную папку.
3. Нажмите **Пуск**, введите `cmd`, найдите «Командная строка», нажмите на неё правой кнопкой мыши и выберите **«Запуск от имени администратора»**.
4. В открывшемся окне командной строки перейдите в папку с распакованным файлом `GetHelpCmd.exe` (например, с помощью команды `cd C:\путь\к\папке`).
5. Выполните одну из следующих команд в зависимости от вашей ситуации:

   - **Удалить обнаруженную установленную версию Office** (автоматическое определение):
     ```cmd
     GetHelpCmd.exe -S OfficeScrubScenario -AcceptEula
     ```

   - **Удалить конкретную версию Office** (например, Office 2021):
     ```cmd
     GetHelpCmd.exe -S OfficeScrubScenario -AcceptEula -OfficeVersion 2021
     ```
     Допустимые значения для параметра `-OfficeVersion`: `All`, `M3652024`, `2021`, `2019`, `2016`, `2013`, `2010`, `2007`.

   - **Удалить все версии Office**:
     ```cmd
     GetHelpCmd.exe -S OfficeScrubScenario -AcceptEula -OfficeVersion All
     ```

6. Дождитесь завершения сценария. В случае успеха в окне командной строки появится сообщение:  
   `00. Успешно выполнен этот сценарий. Рекомендуется перезапустить компьютер, чтобы завершить все остальные задачи очистки.`
7. Перезагрузите компьютер для завершения очистки.

> **Примечания**:
> - Сценарий работает без графического интерфейса и не выводит промежуточных уведомлений — дождитесь финального сообщения.
> - Перед запуском закройте все приложения Office (Word, Excel, Outlook и т. д.), иначе сценарий завершится с ошибкой `06. Программы Office запущены...`.
> - Если на компьютере установлено несколько версий Office, автоматическое определение не сработает — укажите нужную версию явно через `-OfficeVersion`.
> - Для Office 2024 используйте параметр `-OfficeVersion M3652024`.

### Шаг 2: Скачивание Office Tool Plus (OTP)
1. Перейдите на [официальный сайт](https://otp.landian.vip/en-us/download.html)
2. Скачайте последнюю версию (рекомендуется вариант *Office Tool Plus with runtime*).
3. Распакуйте архив в любую удобную папку и запустите `OfficeToolPlus.exe` от имени администратора.

### Шаг 3: Обход блокировки скачивания из РФ (если необходимо)
Если у вас не скачивается сам Office или не открывается сайт OTP без VPN, используйте обход блокировки:
1. Заходим на сайт Gravesoft.dev в раздел [Bypass Microsoft Geoblocking](https://gravesoft.dev/bypass-russian-geoblock)
2. Находим подраздел "Solution 1" (если не помог, то пользуемся "Solution 2")
3. Копируем скрипт для командной строки, которую нужно запустить от имени администратора `reg add "HKCU\Software\Microsoft\Office\16.0\Common\ExperimentConfigs\Ecs" /v "CountryCode" /t REG_SZ /d "std::wstring|US" /f`

### Шаг 4: Установка Office через OTP
1. В программе Office Tool Plus перейдите в раздел **«Развертывание»** (Deployment) в левом меню.
2. В блоке **«Продукты»** нажмите кнопку **«Добавить продукты»**.
3. В появившемся окне выберите нужный продукт (например, *Office LTSC Professional Plus 2024* или *2021*), а после необходимые компоненты (Word, Excel, PowerPoint и т.д.).
4. В блоке **«Языки»** нажмите кнопку **«Добавить языки»** и выберите **русский язык**.
5. В блоке **«Развернуть Office»** настройте параметры:
   * **Режим развертывания**: выберите **Установка** (Install).
   * **Архитектура**: выберите **64-бита** (рекомендуется для большинства современных ПК).
   * **Канал обновлений**: выберите нужный (например `Office 2024 бесcрочный (корпоративный)`)
   * **Установочный модуль**: оставьте **Office Deployment Tool**.
6. Нажмите кнопку **«Начать развертывание»** и дождитесь окончания процесса (интернет должен быть стабильным).

### Шаг 5: Активация (Ohook)
1. Перейдите на сайт Massgrave.dev, найдите раздел [Activate Windows / Office](https://massgrave.dev/).
3. Запустите PowerShell от имени администратора и введите команду, указанную на сайте `irm https://massgrave.dev/get | iex`
4. В появившемся меню выберите пункт под номером 2 `Ohook | Office | Permanent`
5. Затем пункт под номером 1 `Install Ohook Office Activation`
6. Дождитесь сообщения **`Office is permanently activated.`** (Office активирован навсегда).

> 💡 **Важное замечание по поводу предупреждения WPA:**
> Скрипт активации может выдать предупреждение о большом количестве записей в реестре WPA (например, "A large number of WPA registries have been found"). **Если ваш компьютер работает нормально, а в Диспетчере задач нет процесса `sppsvc.exe`, который нагружает ЦП на 100%, — просто проигнорируйте это сообщение.** Не пытайтесь чистить реестр WPA без острой необходимости, чтобы не сбросить активацию Windows.

### Шаг 6: Удаление OTP
После успешной установки и активации Office программу **Office Tool Plus можно удалить**. Она нужна была только для скачивания оригинального дистрибутива. Удаление OTP никак не повлияет на работу самого Office.
