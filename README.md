# Free-Install-Microsoft-Office
This repository provides detailed instructions on how to install Microsoft Office for free

## Скачиваем приложение/утилиту Office(R)tool:
1. Заходим на англоязычный сайт [My Digital Life](https://forums.mydigitallife.net) в статью [Office(R)tool](https://forums.mydigitallife.net/threads/office-r-toolproject.84450/). На территории РФ сайт может быть заблокирован, поэтому стоит заходить с помощью VPN. Также, чтобы статья отображалась в полном ее содержании, нужно зарегистрироваться на сайте.
2. Office(R)tool для скачивания с любого сайта: 
- (https://www.mediafire.com/file/6wsko6huw9tbwnz) 
- (https://www.upload.ee/files/15790511/OfficeRTool.7z.html) 
-- INFORMATION: 
 File: OfficeRTool.7z 
 Password: 2023 
ПУНКТ B 
-- На компьютере создаем новую пустую папку и называем её OfficeRtool (в названии 
папки не должно быть никаких знаков и пробелов). 
-- В эту папку (OfficeRtool) скачиваем файл с одного любого сайта из (ПУНКТ A). 
-- Если на компьютере есть АНТИВИРУС (приложение для защиты компьютера), то 
нужно выключить антивирус на время установки и поместить папку OfficeRtool в белый 
список антивируса (добавить в исключение, чтобы антивирус не ругался и не мешал 
работать). 
-- Ещё создаём пустую подпапку в папке OfficeRtool под названием Office* (где * — это 
год офиса или именование). 
ПУНКТ C 
-- Открываем файл в папке OfficeRtool под названием "OfficeRTool.cmd". 
-- Ждём пока идёт загрузка. 
-- Приложение OfficeRtool запросит согласие на её использование, нажимаем "да" = 
английскую букву "A". 
-- Потом откроется главное меню приложения. 
-- Набираем на клавиатуре (английский язык) букву D - то есть выбираем пункт D. 
 Английский - "DOWNLOAD OFFICE OFFLINE INSTALL PACKAGE" 
 Русский - "Загрузить пакет для автономной установки Office" 
-- Открывается новое окно: 
DownloadPath: "C:\Users\Admin\Downloads\OfficeRtool\Office2021" 
Channel-ID: not set 
Office build: not set 
Language: ru-ru (Russian) 
Architecture: x64 
________________________________________________________________ 
Set new Office Package download path or press return for 
Set Office Package Download Path = "C:\Downloads> 
-- Переходим в проводник (загрузки) и копируем путь к папке Office* (где * — это год 
офиса или именование) (##ПУНКТ В). 
-- Вставляем этот путь сразу без пробелов: 
Set Office Package Download Path = 
"C:\Downloads>C:\Users\Admin\Downloads\OfficeRtool\Office2021 
-- Идёт процесс загрузки, загружается таблица со значениями: 
Download path saved. 
"Public known" standard distribution channels 
Channel Name - Internal Naming Index-# 
________________________________________________________________ 
Current (Retail/RTM) - (Production::CC) (1) 
CurrentPreview (Office Insider SLOW) - (Insiders::CC) (2) 
BetaChannel (Office Insider FAST) - (Insiders::DEVMAIN) (3) 
MonthlyEnterprise - (Production::MEC) (4) 
SemiAnnual (Business) - (Production::DC) (5) 
SemiAnnualPreview (Business Insider) - (Insiders::FRDC) (6) 
PerpetualVL2019 - (Production:LTSC) (7) 
PerpetualVL2021 - (Production:LTSC2021) (8) 
Manual_Override (set identifier for Channel-ID's not public known) (M) 
Exit to Main Menu (X) 
Set Channel-Index-# (1,2,3,4,5,6,7,8,M) or X or press return for Current > 
-- Мы выбираем Office, который нам нужен (2019[7] или 2021[8]). И сразу пишем 
цифру (цифры находятся справа), которая подходит под эту строку: 
Set Channel-Index-# (1,2,3,4,5,6,7,8,M) or X or press return for Current >8 
-- Высвечивается новая строка: 
Set Office Build - or press return for 16.0.14332.20582> 
-- Нажимаем ENTER - соглашаем. 
-- Высвечивается много языков. Мы пишем либо Russian или подтверждаем строку 
(нажимаем ENTER): 
Set language[s] Value[s] - or press return for ru-ru> 
-- Выбираем скольки разрядная операционная система компьютера (х64 или х86). 
Можно эту характеристику посмотреть в (настройках -> система). 
-- Идёт загрузка 10 - 20 минут (зависит от скорости интернета). 
-- После полной загрузки вас выбросит автоматически на главное меню. 
ПУНКТ D 
-- Набираем i в главном меню приложения (английский язык) - выбираем пункт i. 
 Английский - "INSTALL OFFICE FROM OFFLINE INSTALL PACKAGE-IMAGE" 
 Русский - "Установить Office из оффлайн установить пакет-изображений" 
-- После выбираем созданный нами ранее Office: 
Set Office Package Download Path = "C:\Users\Admin\Downloads\OfficeRtool\Office2021" 
> 
List of available installation packages 
1 ru-ru_Office_PerpetualVL2021_x64_v16.0.14332.20582 
Enter package number > 
-- Пишем сразу 1 (номер под которым высветилось). 
-- Выбираем пункт 3 - пишем сразу цифру 3 (номер под которым высветилось). 
Office Professional Plus 2021 Volume 
-- Выбираем, что нам нужно установить. ENTER - нажимаем для того, что НУЖНО. D - 
нажимаем для того, что НЕ НУЖНО. 
-- Пример: 
Disable Word install> ENTER (БУДЕТ загружено) 
Disable Excel install> D (НЕ БУДЕТ загружено) 
-- Высвечивается таблица того, что мы выбрали или не выбрали. 
-- Появляется надпись: 
Английский - "(ENTER) to install, (C) create an installation package, (R) start installation, (E) 
exit to the main menu >" 
Русский - "(ENTER) для установки, (C) создать пакет установки, (R) начать установку, (E) 
выйти в главное меню >" 
-- Пишем ENTER – сразу устанавливаем. 
-- Идёт загрузка. 
-- АКТИВАЦИЯ И ОБНОВЛЕНИЕ АКТИВАЦИИ 
-- Выбираем в меню приложения пункт К и активируем (проверяем, не активировалась 
ли само. Тут нет ничего плохого!) 
 Английский - "START OR RENEW KMS ACTIVATION" 
 Русский - "Начать или продлить активацию KMS" 
-- Каждые 150 дней заходим в приложение и 
обновляем активацию
